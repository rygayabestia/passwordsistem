Хранитель паролей
Это проект по менеджменту паролей от сайтов, аккаунтов и др. Само приложение консольное. В приекте используютяс два типа шифрования для двух типов пароля.
1. Для пароля от аккаунта функция хеширования
2. Для пароей от сайтов XOR по ключу пароля аккаунта

Создан для того чтобы было место для записи паролей, когда не хочется или кажется небезопасным хранить их в заметках
Комментарии к функциям кода прописаны в проекте.
